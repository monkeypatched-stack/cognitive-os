# Project: CognitiveOS v1.0 Extraction

## Objective

Extract `CognitiveOS` into an independent, pip-installable repository that provides a complete cognitive runtime with zero required external dependencies.

The repository should function as a standalone SDK while allowing optional integration with MonkeyBrain's cognitive pipeline through dependency injection.

---

## Design Principles

* Zero required runtime dependencies beyond the Python standard library.
* Pure domain model with no HTTP, messaging, databases, or framework dependencies.
* Optional cognitive pipeline via dependency injection.
* Stable public API suitable for long-term versioning.
* Easy to embed into simulations, games, robotics, enterprises, and research projects.

## Dependency Injection

### Standalone (no pipeline)

```python
from cognitiveos import Actor, CognitiveOS

actor = Actor(entity_id="alice", actor_type_id="human")
os = CognitiveOS()
os.set_actor(actor)
decision = os.synthesize()
```

### Plugin (with pipeline)

```python
from monkeypatched.pipeline import BeliefFormation

os = CognitiveOS()
os.set_actor(actor)
os.set_engine(BeliefFormation())
await os.tick()
```

No compile-time dependency on monkeypatched.
